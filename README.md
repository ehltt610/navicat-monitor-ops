## Navicat Monitor 是什么，"无代理"到底有多香

很多监控工具要求你在每台被监控的服务器上装一个 Agent（代理进程），每台装一个，管十台就得管十个 Agent 的版本、权限、日志……维护成本悄悄翻了好几倍。

Navicat Monitor 的做法完全不同。

它把监控服务安装在你本地的一台电脑或虚拟机上，然后通过 SSH 或 SNMP 去"读"那些被监控服务器的数据。被监控的服务器什么都不用装。换台服务器？不用重新部署。服务器在防火墙后面？没关系，SSH 通道打通就行。

这个设计的意义不只是省事。从安全角度看，不在生产服务器上安装任何第三方进程，也意味着更低的入侵面。

部署完成后，用浏览器访问监控面板就行了。在办公室、在家、在手机上，只要有网，随时能看到服务器现在跑得怎么样。

## 核心功能拆开来说

### 实时性能看板

Navicat Monitor 提供一组丰富的实时和历史图表，把 CPU 负载、内存使用率、磁盘 I/O、网络流量、数据库连接数等 20 多个指标可视化展示出来。

交互式仪表板列出所有受监控的实例，每个实例的健康状态一眼就看出来，哪台需要重点关注直接高亮标出。

多台服务器的数据可以叠在同一张图上对比，排查问题时不用来回切窗口。

### 查询分析与慢查询定位

这可能是让 DBA 最省心的功能之一。

Navicat Monitor 的查询分析器会显示所有正在运行的查询摘要，帮你识别：累积运行时间最长的查询、响应时间不正常的慢查询、死锁情况。

你可以创建追踪来收集查询执行数据，事后拿来分析。PostgreSQL 用户还有 SQL 性能分析工具，可以图形化展示查询执行计划的每个组件。说白了，就是帮你找到哪条 SQL 在拖后腿，然后给你分析为什么慢。

### 性能警报系统

Navicat Monitor 内置超过 40 个可自定义的警报策略，比如"CPU 利用率超过 90% 且持续超过 30 分钟时触发警报"。

触发后怎么通知你？支持电子邮件、短信、SNMP 陷阱，以及 Slack。关键是它不只告诉你"出问题了"，还提供根本原因分析——服务器指标、性能统计数据、硬件使用率和历史数据全都有，帮你定位问题出在哪一层。

### 复制监控

对于跑主从复制架构的团队，这个功能相当实用。Navicat Monitor 用图形化的方式展示主服务器和从服务器之间的层级关系，让你一眼看到整个复制拓扑的当前健康状态，出现复制延迟或异常时立刻报警。

### 用户权限与团队管理

支持基于角色的访问控制（RBAC），内置管理员、DBA、操作员三种预定义角色，也可以自定义权限。

对接企业环境的 OpenLDAP 或 Active Directory，省去重新建账号的麻烦。
